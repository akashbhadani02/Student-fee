Actual Excel workflow

આ projectમાં template-only export નથી. Export થતી Excelમાં હાલ websiteમાં રહેલો actual student data, branch, fee values અને collection history આવે છે.

  1. Export Actual .xlsx કરો.
  2. Excelની Students sheetમાં Name / Branch / Total Fee / Paid Fee edit કરો. Existing ID same રાખશો તો એ જ student update થશે.
  3. નવી row ઉમેરશો તો blank ID રાખી શકો; import વખતે ID auto-generate થશે.
  4. એ જ All Data sheetના Collection History sectionમાં date/branch collection edit અથવા નવી row add કરી શકો.
  5. Excel save કરીને એ જ file Import .xlsx કરો. Website state actual Excel values પ્રમાણે rebuild થશે.

Excelમાં પણ automatic calculation છે: Total Fee અને Paid Fee edit કરશો તો Paid Fee 25%, Remaining, Status, Summary totals અને branch counts Excel formulasથી automatic recalculate થશે. Student ID Excelમાં નહીં આવે; website import વખતે row-wise automatic generate થશે.

Paid Fee 25% અને Remaining website/Excel formulasથી automatic ગણાય છે. Original supplied workbookમાં Total Fee values blank હોવાથી dashboardનું Total Fee શરૂઆતમાં ₹0 રહેશે; તમે Excel અથવા Students screenથી Total Fee ભરી શકો છો.
